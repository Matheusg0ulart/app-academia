# Estrutura do Banco de Dados - PostgreSQL 🐘

Esta pasta armazena o histórico de esquemas e dados iniciais do banco de dados relacional **PostgreSQL** do projeto FitLife AI.

## Estrutura de Pastas

- `migrations/`: Scripts SQL/JS encarregados da criação, alteração e controle de versão das tabelas.
- `seeds/`: Scripts para inserção de dados iniciais ou mockados para testes (ex: catálogo inicial de exercícios, alimentos base, etc.).

> **Observação:** Nesta Etapa 1, nenhuma tabela foi criada ainda para priorizar a estrutura base e a arquitetura limpa. As tabelas serão adicionadas gradualmente nas etapas seguintes.
